Voice Biomarker Analysis

The system extracts and analyzes multiple categories of voice features that are scientifically proven to correlate with Parkinson's disease progression.

  • Frequency Features: Jitter, fundamental frequency variations, harmonic-to-noise ratio
  • Amplitude Features: Shimmer, signal-to-noise ratio, amplitude perturbations
  • Spectral Features: MFCCs, spectral centroid, bandwidth, formant analysis
  • Temporal Features: Speech rate, pause duration, voice onset time
  • Nonlinear Features: Recurrence patterns, chaos analysis, complexity metrics
